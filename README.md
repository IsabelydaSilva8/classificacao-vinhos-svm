# Classificação de Vinhos com Machine Learning (SVM) 

Este projeto implementa um modelo de Inteligência Artificial utilizando o algoritmo
**SVM (Support Vector Machine)** para classificar três tipos diferentes de vinhos. 
O modelo analisa 13 características químicas (como teor alcoólico, ácido málico, 
intensidade da cor, entre outras) para identificar a categoria correta de cada amostra.

##  Resultados do Modelo

Após a divisão da base de dados e o treinamento do algoritmo, o modelo foi avaliado 
com dados inéditos (dados de teste), alcançando o seguinte resultado:
* **Acurácia Geral:** **77,42%** de acertos na classificação dos vinhos.
